# DawnDusk Releases

Official release downloads for **DawnDusk (朝暮)** — a private quick-notes app that turns your notes into AI insights.

- Website: <https://dawndusk.fayanji.com>
- App Store / Google Play links are available on the website.

## Direct APK downloads

Each release carries the Android APKs, signed with the same key as the Google Play build (they upgrade / replace each other):

- `DawnDusk-<version>-android.apk` — arm64-v8a (recommended, most devices)
- `DawnDusk-<version>-android-universal.apk` — all ABIs (fallback for 32-bit devices)

Browse all versions on the [Releases](../../releases) page.

> Source code lives in a private repository; this repo only hosts release artifacts.
